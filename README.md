# 👑 Queen Jewelry Live Valuation Portal

An elegant, full-stack web application engineered for **Queen Jewelry** to track real-time commodity spot markets. It features an interactive gold and silver melt value calculator and a multi-column pricing distribution matrix tailored for luxury brand evaluations.

🚀 **Live Frontend URL:** [https://vercel.app][https://queenjewelry-dashboard.vercel.app/)  
📡 **Live Backend API Engine:** [https://onrender.com](https://precious-metals-dashboard.onrender.com)

---

## 🎨 Premium Visual Interface

*   **Luxury Workspace Architecture:** Dark-theme matrix highlighted with neon cyan, emerald green, and classic gold (#d4af37) tones.
*   **Vector Crown Geometry:** Embedded custom responsive SVG royal crown emblem matching institutional branding styles.
*   **Decoupled Navigation Footer:** Direct, anchored links to the official storefront and community channels.

---

## ⚙️ Core Technical Features

*   **Purity Mathematical Scaling:** Node.js processing layers execute dynamic weight transforms based on precise karat purity constraints:
    *   **Gold 24K:** Pure gold benchmark basis.
    *   **Gold 21K:** computed at exactly 87.5% pure market metrics (21/24).
    *   **Gold 18K:** computed at exactly 75.0% pure market metrics (18/24).
    *   **Silver 925 Italy:** sterling silver metrics calculated at 92.5% purity benchmarks.
*   **Melt Value Estimator:** Real-time frontend calculators processing custom user gram inputs and asset selections into automated USD payouts.
*   **Dual-Column Infrastructure:** Segmented layout splits pricing tracks cleanly between global Ounce rates and local Gram variables.

## 🛠️ Local Deployment Guide

Follow these instructions to run the full-stack architecture locally on your computer.

### 1. Clone the repository
```bash
git clone https://github.com
cd precious-metals-dashboard
```

### 2. Startup the Backend Engine
```bash
cd backend
npm install
npm start
```
*The service initializes locally at `http://localhost:5000`.*

### 3. Startup the Frontend Server
Open a second, separate terminal split in your workspace:
```bash
cd frontend
npm install
npm run dev
```
*The local development server launches instantly at `http://localhost:5173`.*
